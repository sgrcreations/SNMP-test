# 11 — Dashboard

Route: `/dashboard`  
Permission: `dashboard.view`  
API: `GET /api/v1/dashboard`

## Cards (Phase 1)

- Total Devices
- Online / Offline
- Open Alerts (placeholder)
- CPU / Memory / Temperature placeholders
- Bandwidth / Last Poll placeholders
- Recent Devices table
- Polling enabled flag from Settings

## UX Features

- Responsive enterprise shell
- Light / Dark mode (class strategy + localStorage)
- Breadcrumbs
- Sidebar navigation with Phase 2 placeholders

## Phase 2 Chart Ranges

ApexCharts ranges: 1 Hour, 24 Hours, 7 Days, 30 Days, Custom.
